## 一、文档说明

本文档是测试用例的**设计说明**，描述"测什么、怎么测、预期结果是什么"，供不阅读代码的评审快速了解测试覆盖范围。对应的实际执行结果（通过/失败、执行耗时等）请见`docs/TEST_REPORT.md`。

- **用例编号规则**：`TC-模块缩写-序号`，例如`TC-AUTH-01`表示"认证模块第1条用例"。
- **对应代码位置**：每条用例末尾标注了实现该用例的测试文件和函数名，方便对照查阅。

## 三、认证与会话模块

| 用例编号 | 测试目的 | 前置条件 | 测试步骤 | 预期结果 |
|---|---|---|---|---|

| TC-AUTH-02 | 验证用户名重复时注册被拒绝 | 已存在一个账号 | 用相同用户名再次注册 | 返回400，提示用户名已被注册 |
| TC-AUTH-03 | 验证用户名长度校验 | 无 | 用少于3个字符的用户名注册 | 返回422参数校验错误 |
| TC-AUTH-04 | 验证密码长度校验 | 无 | 用少于6位的密码注册 | 返回422参数校验错误 |
| TC-AUTH-05 | 验证正常登录流程 | 已注册一个账号 | 用正确用户名密码调用`POST /api/auth/login` | 返回200，颁发一个新的令牌（与注册时不同） |
| TC-AUTH-06 | 验证密码错误时登录被拒绝 | 已注册一个账号 | 用错误密码登录 | 返回401，提示用户名或密码错误 |
| TC-AUTH-07 | 验证登录不存在的账号被拒绝 | 无 | 用一个从未注册过的用户名登录 | 返回401 |
| TC-AUTH-08 | 验证未登录访问个人信息接口被拒绝 | 无 | 不带令牌调用`GET /api/users/me` | 返回401，提示未登录或令牌缺失 |
| TC-AUTH-09 | 验证带令牌能正确获取当前用户信息 | 已登录，持有有效令牌 | 带令牌调用`GET /api/users/me` | 返回200，用户信息与登录账号一致 |
| TC-AUTH-10 | 验证退出登录后令牌立即失效 | 已登录 | 调用`POST /api/auth/logout`后，再用同一令牌访问任意接口 | 退出登录返回204；后续用该令牌的请求返回401 |
| TC-AUTH-11 | 验证过期令牌被拒绝 | 已登录，手动将令牌过期时间改为已过去 | 用已过期令牌访问接口 | 返回401，提示登录已失效 |

| TC-INT-09 | 验证提交空回答被拒绝 | 面试已开始 | 提交空字符串作为回答 | 返回422参数校验错误 |
